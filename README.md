# Pet - Your Gamified Study Companion 🎓✨

Pet is an interactive, gamified study application built to make learning efficient and engaging. Whether you're studying for exams or learning a new language, Pet helps you organize your knowledge, review it using spaced repetition (SM-2), and test yourself with quizzes and exercises.

## Features

- **📚 Course Management:** Organize your study materials into Courses, Modules, and Chapters.
- **✨ AI-Powered Generation:** Automatically generate comprehensive study notes, summaries, flashcards, and quizzes from your course materials using local or cloud AI models.
- **🧠 Spaced Repetition (SM-2):** Review your flashcards using the proven SM-2 algorithm for maximum retention.
- **🏆 Gamification:** Earn XP, level up, unlock badges, and maintain a study streak to stay motivated.
- **📝 Markdown Notes:** Write and edit rich study notes with built-in Markdown and mathematical equation (LaTeX) support.
- **🚀 Auto-Updater:** Stay up-to-date automatically with GitHub releases.
